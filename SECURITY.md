# Security Policy

KoZove is an early alpha. The development Compose setup is **not production hardened**.

## Reporting a vulnerability

Please **do not create a public issue** for exploitable security problems or send secrets in a public discussion.

Use **GitHub private vulnerability reporting** on the repository's Security tab. The repository owner should enable it in **Settings → Security → Code security and analysis** before publication. If it is unavailable, contact the maintainer privately using a contact method on their GitHub profile.

A useful report includes a summary, affected component, reproducible steps with synthetic data, and potential impact. Please avoid accessing real users' data.

## Supported versions

Security fixes currently target the latest alpha code on the `main` branch. Older development snapshots are not supported.
